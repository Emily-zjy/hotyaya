# MD Companion — approved design

User approved the researched component selection on 2026-10-09. Build a desktop Obsidian plugin using public APIs, white minimalist UI, current-file enable button, animated pet with contextual comments, clickable chat, real streamed tool steps and reversible text edits. Operations: editable PPTX, HTML slides, HTML article, natural Chinese/English polish, web research with sources, explanation, selected-text translation, corporate illustration, Markdown table.

Approved reuse: LangChain.js/LangGraph.js, assistant-ui, shadcn-style Radix components, Lucide, VS Code Pets (individual assets must have traceable license), PPT Master, Frontend Slides, Baoyu skills, Humanizer/Humanizer-zh, Fabric, Zod/remark-gfm. SearXNG and Crawl4AI configurable external services. No pretense of bundled model or free image generation. No arbitrary skills' shell commands exposed to the model.

Architecture: TypeScript plugin owns Obsidian editor operations and React UI. Bundled Node worker runs on loopback with a per-launch bearer token, started using Electron-as-Node on desktop; also runnable through npm. Only explicit run requests send the current file or selected text to configured model. Python helper is used for PPT Master's audited export pipeline. Secrets use official SecretStorage; worker can discover explicitly supported environment variables without returning their values. Plugins' arbitrary files are not scanned. Worker cannot write into the user's vault: artifacts are copied by the plugin through Vault APIs.

Interaction: enable per file; idle, looking/reading, busy, success/error pet states; debounced/cooldown comments only for enabled active notes and with opt-out. Chat has step status, expandable details, actual elapsed time, streaming text, cancellation, retry, artifact save, diff/apply, copy. Long requests carry an editor snapshot and reject stale replacement. Modified text retains Obsidian undo support. Generated HTML opens through sandboxed preview. Plugin unload cancels work and cleans resources.

Distribution: build manifest/main.js/styles.css/worker.cjs/vendor skills and license notices into dist/md-companion. Exact upstream commits recorded. Model, image, Python and search service configuration limitations are displayed, never reported as successful operations. Desktop-only with minAppVersion 1.11.4.
