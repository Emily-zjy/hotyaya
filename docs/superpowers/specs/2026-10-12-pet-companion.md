# 陪伴宠物升级（已确认）

基线：hotyaya 0.2.0，本地 main.js、worker.cjs、styles.css 与已安装版本 SHA-256 相同。GitHub 仓库 Emily-zjy/hotyaya，开发分支 feat/pet-companion。

采用本地开源逐帧素材与道具动画。保留小黄鸭，新增 oneko 猫；逐项保留素材来源与许可。透明悬浮宠物支持大小、命名、抚摸、喂食、玩球、睡觉、摸鱼、专注、拖动。点击继续打开聊天，独立互动入口和右键打开宠物面板。

独立 PetCompanion 负责交互、动画、计时器与气泡；pet-model 负责配置校验、动作映射和互动记录。工作状态优先于手动动作及随机空闲行为。所有 Action 均有可辨识道具与文案；完成短暂庆祝，失败安慰。名字、形象、大小、位置、陪伴起点、亲密度和最多 20 条日记存入插件配置，旧配置自动补齐。无离线惩罚，无互动网络请求。

安静模式关闭主动气泡，减少动态效果偏好关闭帧循环与 CSS 动画。计时器卸载清理，位置保持在视口内，拖动不会误开聊天，面板支持键盘及 Escape。

验证：模型单测、React 交互与状态优先级测试、原有回归测试、类型检查、构建打包及浏览器预览。安装包交付，不自动发布 GitHub。
